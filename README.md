### [pt-br]
# Tripzy – Landing Page de Viagens

Projeto desenvolvido como desafio de criação de uma landing page utilizando HTML e CSS (JS opcional).

## Descrição

A proposta consiste em desenvolver uma página web com:

- Banner dentro da tag `<main>`
- Navegação interna com `<nav>`
- No mínimo três seções
- Navegação por âncoras utilizando `id`
- Efeitos de hover nos elementos interativos
- Uso de tags semânticas

A página simula uma agência de viagens fictícia chamada **Tripzy**.

### [en]
# Tripzy – Travel Landing Page

This project was developed as a challenge to create a landing page using HTML and CSS (optional JS).

## Description

The objective was to build a webpage containing:

- A banner inside the `<main>` tag
- Internal navigation using `<nav>`
- At least three sections
- Anchor navigation using `id`
- Hover effects on interactive elements
- Proper use of semantic HTML tags

The page represents a fictional travel agency called **Tripzy**.
